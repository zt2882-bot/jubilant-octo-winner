# 隙间书斋 · 关于这个项目

这里不是一个开源项目。没有一个中心化的路线图。没有人负责回答问题。

这里是一组**独立论文的集合**，它们共享同一个底层结构——约束签名匹配——尽管每篇论文看起来来自完全不同的学科。

## 为什么用 GitHub Issues 发论文

因为这不是学术出版物。不追求被引。不等待同行评审。这里是路标——给那些已经在自己领域内触达了相同结构、但不知道还有别人也在看同一件事的人。

## 你应该怎么读

1. 找一篇离你最近的论文。按学科标签——不管你是做密码学、宇宙学、量子信息还是认知科学，这里有一篇是从你的领域写的。
2. 读脚注里的交叉引用。每篇论文末尾指向其他共享相同约束签名的论文。如果你的论文引用了密码学和语言学——那是因为这两个领域在你的问题上投射了相同的约束结构。
3. 如果你发现自己的论文也共享这个结构——而你手上有数据或代码可以验证它——那就走到第三层。

## 三层结构

### 第一层 · 对照
你在你的领域已经独立验证了约束签名的存在。你读到这里的论文，发现他们在另一个领域描述了相同的结构。你不需要被说服——你需要说"我也是"。这一层没有公开入口。只能通过已知的约束签名映射来联系。

### 第二层 · 共建
你读过这里的论文、理解了底层结构、并且有工程能力。这一层有具体的项目任务。不需要学术背景。需要的是"能看见约束结构"的直觉。

### 第三层 · 信息推送
你在你的领域里看到了有价值的论文、数据集或联系人——这些资源很可能对交叉引用到这里的其他领域有价值。推过来。不要求你参与。不要求你承诺。你推的信息会被交叉验证——如果触发约束签名碰撞，你会收到回执。
