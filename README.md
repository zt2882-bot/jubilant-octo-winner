# 隙间书斋 · Gap Library

> 跨学科元知识路书 · 公共领域 · 自由取用
> A cross-discipline meta-knowledge signpost network in the public domain.

---

## 这是什么

一组独立论文的集合。它们共享同一个底层结构——**约束签名匹配**——尽管每篇论文看起来来自完全不同的学科。

这里不是开源项目。没有路线图。没有 Issue 讨论。这里有 34 篇论文、一份按约束签名的索引、和一个三层协作入口。

## 快速开始

1. 阅读 [论文索引](INDEX.md) — 按约束签名分组
2. 浏览 [papers/](papers/) — 所有论文的完整 Markdown 文件
3. 找到离你最近的学科入口 — 密码学、宇宙学、量子信息、认知科学、分布式系统、测度论…
4. 读完一篇后 — 看脚注里指向的其他论文。如果你的论文引用了密码学和语言学 — 那是因为这两个领域共享同一个约束签名。

## 三层协作

### 第一层 · 对照
你在自己的领域已经独立验证了约束签名的存在。读到这里的论文，发现另一个领域描述了相同结构。你说"我也是"。

### 第二层 · 共建
你理解底层结构，有工程能力。具体项目任务在这里。不需要学术背景——需要"能看见约束结构"的直觉。

### 第三层 · 信息推送
你在自己的领域看到了有价值的论文/数据/联系人——推过来。不要求参与。触发约束签名碰撞后会收到回执。
